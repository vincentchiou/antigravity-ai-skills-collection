# Output Files Convention (作品儲存規範)

> **最高原則**：  
> 本專案資料夾內所有新生成、導出的內容作品（包含海報圖片、設計文稿、企劃書、Word 文件、Markdown 報告、資料整理等），**一律強制儲存至 `output作品` 資料夾**：
> `h:\我的雲端硬碟\Agent\project\AI助理\output作品\`

### 規則要點：
1. **作品目錄**：`./output作品/`
2. **格式要求**：以實體文件形式儲存（如 `.jpg`、`.png`、`.docx`、`.md`、`.pdf` 等）。
3. **對話回覆要求**：每次產出作品後，必須在對話中附上該作品在 `output作品` 目錄下的點擊連結（`file:///...`），方便使用者直接點開查閱。
